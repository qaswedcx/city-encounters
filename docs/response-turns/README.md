## 結算與場景

新增等待節點標記 `awaitingReply:true`，驗證器不允許它同時成為 result 終端或無選項延續。UI 沿原 choices 顯示玩家回應，只有合法終端才提供結束。場景結尾投影也只接受 result 終端，不再把問題記成最後回應。

每條新增回覆各有角色台詞、表情與動作；不在選擇時發獎。原 result／delta 移到新終端，兩個回覆都保留原結果及關係效果。不同回覆改變當次反應；不是額外戀愛測驗，也不使原失敗因一句補救就成功。

追加回覆不設 effect，避免覆蓋原 romance／friendship／pause 等路徑記憶；新選擇仍追加至 trace。結束依原意願／重試與 pending 機制結算一次，不新增約定或正式遊戲地點。文中的約飯／時間安排仍是敘事，不會另建行程系統。
