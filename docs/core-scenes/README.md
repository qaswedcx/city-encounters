# 三位核心角色的 21 段主線演出

本次從已合併《新的配方》樣本的 main `192280a` 延伸其餘 20 段主線。仍由城市探索的深入交流進入，沒有獨立展示頁或跳關按鈕。舊事件清理 PR #12 不在本次基底，這份變更沒有替代或合併該 PR。

每段增加專屬場景開場、動作及逐節點表情。保留 story.js 的問題、選項、分支、終端回應及原有結算；芷妍 story6 保留先前已完成的細分演出。開場與重要追問分段閱讀，選項顯示時保留實際問句，不讓動作旁白取代問句。

## 素材與維護

- `js/scene-data.js`：20 段主線的逐節點演出指示；不是另一份事件圖。既有芷妍 story6 的演出仍在 `js/scenes.js`。
- `assets/scenes/town-scenes.webp`：1774×887，三欄兩列的六個等大 4:3 場景，依序市場、圖書館、百貨、社區、公園、咖啡廳。單一 4:3 舞台以 CSS 平移選取一格，不用任意偏移補位，320px 也維持相同比例。
- `assets/scenes/cafe-closing.webp`：芷妍兩段夜間咖啡廳事件沿用的樣本內景。
- 各角色 `daily-expressions.webp`：日常服三欄透明圖集；若晴、以安 `story-expressions.webp`：工作服；芷妍工作服沿用 `recipe-expressions.webp`。皆為 1774×887，左至右專注、微笑、含蓄低頭。
- 原始標準肖像及 profiles.js 的圖資欄位保留。以原肖像／已生成工作服為參考，經 imagegen 產生一致構圖，再使用 sharp 品質 86 轉為 WebP；本輪新增六個 WebP 約 2.33 MiB，遊戲只讀本機相對路徑，沒有外部圖片 API 或新執行時套件。
- 顯示時只載入當前背景及服裝；同一圖集的表情以三欄座標切換。沿用 240ms 淡入及 reduced-motion。各種寬度不改圖集裁切比例。

## 舊存檔與功能範圍

只對核心角色、官方 ID 及完整官方事件內容都符合的事件啟用。玩家編輯過、舊版尚未結束的事件、非核心角色、一般聊天及 AI 對話保留原呈現。演出是官方事件的即時投影，不需要把新素材或開場塞回存檔事件資料，也不需要刪檔。

沿用 pending.sceneBeat 的可選閱讀進度，關閉、刷新及匯入後接續；原選項／自動延續會重設節拍。閱讀不消耗時段或感情，最後結束按原結果結算一次。保存實際終端回應與 scene 標記，保留原 path、choices、關係及完成紀錄，不重播已完成事件。若晴／以安 story7 根據實際演出過的 story6 分支承接，芷妍仍保留味覺記憶、猶豫重試和樣本後續。

背景載入失敗時保留暖色舞台及地點標示；差分失敗回退該角色標準肖像，姓名與選項始終存在。所有素材都失敗時仍可閱讀並完成事件。
