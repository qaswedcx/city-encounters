# 城市邂逅 v0.3

繁體中文、iPhone直式觸控生活與人物關係模擬。延伸現有遊戲，純HTML／CSS／原生JavaScript，離線對話，不需要後端、帳號、付費AI或外部CDN。

## 遊玩

- 保留社區、傳統市場、百貨公司、咖啡廳、公園、圖書館。移動不耗時間；完整對話或等待耗一個早／午／晚時段。
- 林若晴、蘇以安、陳芷妍各有六組新日常話題，其中三組會記住具體選擇、隔日接續。手動與隨機人物則依工作、興趣、性格、婚姻與家庭產生不同生活話題。
- 打招呼、工作中短暫互動、忙碌拒絕及無新話題時，只有一個結束按鈕。真正的分歧才提供不同台詞或行動，完成後告別措辭不影響結算。
- 一般聊天與人物事件分開結算。日常有完成、續談、提前離開、拒絕、無話題、簡短招呼；關鍵事件另有成功、不推進、暫時失敗、永久失敗及錯過。
- 人物可能主動邀談。看到邀請時可選深入交流；一般聊天不再強制插入重要事件。
- 關係數值0–100；100不自動突破。只有本人同意且關鍵事件成功才進一步發展。友情與拒絕仍有意義，工作、家庭與婚姻不會消失。

## 小鎮地圖 2.0

城市探索使用同一張 2.5D 鳥瞰街區：住宅巷弄、傳統市場、公園、圖書館、咖啡廳與玻璃百貨，透過連續道路、斑馬線與步道相連。點建築直接沿用原有地點探索，移動不耗時間；底部保留城市探索、人物圖鑑、相遇手記。

地圖圓形頭像使用既有正式肖像，點選可查看人物姓名、所在位置，再進入該地點。每處最多三張頭像及 `+N`；窄畫面中的擁擠地點優先顯示兩張及 `+N`，避免遮擋其他地點；完整地點面板仍呈現所有在場人物與原有互動。忙碌、家庭責任、臨時有事及位於家中／辦公室的人物不以地圖頭像招示可相遇；工作中可短暫互動者依原排程顯示。未開放的事件名稱、選項與條件不會出現在頭像預覽。

`assets/town-map.svg` 是無外部依賴的共用地景，`js/town.js` 只將 `Core.prepare/statusAt` 的結果投影到原六個地點，不另存位置、不新增行程或正式地點。時間、事件、關係、AI 聊天與存檔格式沿用原系統。部署請包含新增的 SVG 與 `js/town.js`。定位修正與四種手機尺寸的前後比較見 [手機截圖驗收](docs/map-alignment/README.md)。

## 零程式碼人物編輯器

「人物圖鑑 → 編輯人物」保留v0.2.1工作表單，並加入：

- 婚姻、子女人數及年齡。
- 新增家庭行程，填寫接送、採買、料理、家務、照護等內容，勾選星期、時段與地點。
- 平日與週末三段活動、確定活動／約定，以及即時行程優先順序預覽。
- 「進階模式：人物專屬事件」可設定名稱、前置、數值門檻、時地、意願、重試與期限，按「新增對話」「新增選項」串接節點或設定結果，不需JSON。

所有表單在按「儲存人物」後生效並自動存檔；取消不變更進度。有既有結果或被引用的事件不可直接刪除，修改不會清除關係、記憶或事件紀錄。事件作者仍須自行寫出合理而不同的台詞；引擎不會理解自訂文字的語意。

舊存檔中的「休假」不自動改班。可保留，或預覽職業建議後調整並儲存。每週檢視只顯示固定安排與已知活動，不抽選未來隨機事件。

## 存檔與相容

沿用localStorage鍵 `city-encounters-v1` 及版本3，接受版本1／2／3。新增欄位為可選，保留原人物、工作表單、行程、日誌、關係、故事與記憶；舊的未完成對話可繼續。錯誤匯入不取代有效進度，損壞本機存檔保留原始內容並停止自動覆寫。

「相遇手記」提供JSON檔案及文字備份。Safari可用分享選單存到「檔案」；清除網站資料、無痕模式或更換裝置可能失去本機進度，請定期備份。支援上限2MB的JSON匯入，無跨裝置同步。

## 部署與開發

GitHub Pages部署根目錄 `index.html`、`styles.css` 及完整 `js/`。新增的 `topics.js`、`talk.js`、`editor.js` 也必須一起部署。無須建置。可本機執行 `python3 -m http.server 8000`。

- data.js：人物與地點；core.js：原有規則、資料驗證。
- life.js：事件與關係、工作家庭、位置判定與每週安排。
- topics.js：離線日常話題與延續內容；talk.js：一般對話狀態、冷卻及結算。
- editor.js：中文家庭與事件作者表單；app.js：介面與安全存檔。

核心測試：`node tests/core.test.cjs`、`node tests/life.test.cjs`、`node tests/work-schedule.test.cjs`、`node tests/dialogue.test.cjs`。

瀏覽器開發測試需playwright-core與Chromium：`CHROMIUM_PATH=/usr/bin/chromium node tests/browser-smoke.cjs`。測試依賴不參與遊戲執行。詳見 [GAME_SPEC.md](GAME_SPEC.md) 與 [TESTING.md](TESTING.md)。實體iPhone Safari尚待人工驗收；PR不直接合併或更改Pages發布設定。

## v0.3：人物、生活與靠近

本輪保留原玩法，將重點放在三位核心角色、分層角色檔案與圖像承接。`js/profiles.js` 保存完整人物設定、視覺規格、服裝、事件規劃及素材路徑；三人皆有戀愛、友情與失敗結果，若晴的新路線不再被永久友情鎖住。非核心角色仍可手動／隨機建立。

圖鑑優先排列核心人物，具備大圖、標語、分段解鎖、關係階段、事件與回憶；相遇與對話支援半身圖，關鍵／戀愛後事件支援劇照。三位正式標準肖像已由儲存庫PNG無損轉為WebP接入；工作、約會、表情與劇照變體尚待提供，缺少變體會回退同角色標準肖像，標準肖像也失敗才使用安全輪廓 fallback；詳見 [圖資契約](assets/characters/README.md)。表情與約會版本已預留，尚未新增自動換裝／表情玩法。

存檔沿用 `city-encounters-v1`，schema 升為 4，可匯入版本 1–3；以核心 ID 識別人物，舊檔依原姓名首次識別。工作、家庭、自訂事件、進行中談話與記憶保留；路線以新事件 ID 附加。舊版 56–99 歲角色載入時收斂到 55，其餘進度保留；本版新增、編輯、隨機與新格式匯入統一 18–55。請先匯出舊檔備份。

交付使用 PR，不合併、不部署正式 GitHub Pages。測試命令與未實測限制見 [TESTING](TESTING.md)。

## 官方主線自然對話

三位核心角色的 21 段主線改為各自的語氣、兩至四個選項、部分多輪交流與分支記憶。角色回應自然結束後，以獨立「結束對話」操作結算；原 ID、時地及前置門檻保留。未修改的舊官方事件自動更新，玩家編輯過的事件保留，進行中的舊對話先安全完成再更新，無須重新開局。遷移與節點契約見 [TOWN_STORY.md](TOWN_STORY.md)；部署需包含新增的 `js/story-v1.js` 歷史快照。
